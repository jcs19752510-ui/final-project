# 추가 항목만 별도 정리 (슬라이드 문서 반영분)

## 1. 기준 문서(Single Source of Truth) 명시 규칙

> ⚠️ **기준 문서(Single Source of Truth) 명시**: 같은 프로젝트에 대해 상세 텍스트 기획서와 요약 슬라이드(PDF) 두 버전이 있고, 일부 세부사항(예: API 응답 스키마 구성)이 서로 다르게 표현되어 있습니다. Claude Code에게는 **상세 텍스트 기획서를 1차 기준으로 삼고, 슬라이드는 참고용으로만 사용**하도록 명시하세요. 둘이 충돌하는 항목을 발견하면 "미구현"이 아니라 별도로 "문서 간 불일치"로 표기하게 하세요.

Claude Code 실행 프롬프트에 넣을 때는 아래 규칙 문장으로 사용:

```
상세 텍스트 기획서를 1차 기준 문서로 삼고, 요약 슬라이드는 참고용으로만 사용한다.
두 문서가 서로 다르게 표현된 항목은 "미구현"이 아니라 "문서 간 불일치"로 별도 표기한다.
```
