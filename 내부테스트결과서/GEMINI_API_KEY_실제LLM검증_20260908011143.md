- 배경: 사용자가 Gemini API 키를 2회 제공(1차 키는 유효, 2차로 재발급받은
  키로 최종 반영·검증). MVP 착수 이후 처음으로 Fake가 아닌 **실제
  Gemini 응답**으로 핵심 가치(적응형 질문 생성, AI 채점)를 검증.

## 발견 및 조치
1. **모델 단종**: 코드에 고정돼 있던 `gemini-2.0-flash`가 이미 서비스
   종료(404, "no longer available")됨을 실제 호출로 발견.
2. **1차 교체 모델도 일시 장애**: `-latest` 별칭(`gemini-flash-latest`)로
   교체했으나 그 시점에 구글 쪽 일시적 과부하(503, "high demand")로 실패.
   같은 키로 `gemini-2.5-flash-lite`는 동시에 정상 응답해, 키 문제가
   아니라 특정 모델의 일시적 이슈임을 직접 대조 검증.
3. **최종 조치**: `gemini-2.5-flash-lite`로 모델 고정
   (`src/backend/app/ai/llm.py`, `app/ai/report.py`). Gemini API 예외를
   원시 500이 아니라 표준 503 에러 포맷으로 변환하는 에러 핸들링도 함께
   추가.
