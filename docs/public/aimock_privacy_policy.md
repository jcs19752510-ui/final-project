# aimock 개인정보 처리방침

- 버전: 2026-09-09 (초안)
- 적용 범위: aimock 웹 AI 모의면접 서비스(이하 "서비스")

> ⚠️ **이 문서의 성격에 대한 안내**: 이 서비스는 1인 개발자가 4주 이내로
> 만든 **교육/시연 목적의 MVP(시범 서비스)**입니다. 이 문서는 실제로
> 구현된 데이터 처리 방식을 사실 그대로 설명하는 것을 목적으로 하며,
> 정식 법인의 개인정보 처리방침에 준하는 법적 검토(개인정보보호법상
> 개인정보처리자 지정, DPO 지정, 국외이전 신고 등)를 거친 문서가
> **아닙니다**. 실제 서비스로 운영 전환 시 반드시 법률 검토가
> 필요합니다.

## 1. 수집하는 개인정보 항목

| 구분 | 항목 | 수집 시점 |
|---|---|---|
| 계정 | 이메일, 비밀번호(암호화 저장), 역할(지원자/채용담당자) | 회원가입 시 |
| 면접 내용 | 지원 직무, 질문/답변 텍스트(음성을 텍스트로 변환한 결과) | 면접 진행 중 |
| 생체정보 | 답변 음성 원본, 답변 중 캡처된 얼굴 영상 프레임 | 면접 진행 중(카메라/마이크 사용 시) |
| 코드 제출 | 라이브 코딩 화면에서 작성·실행한 코드와 실행 결과 | 코딩 테스트 진행 중 |
| 평가 결과 | AI가 생성한 점수, 요약, 표정/음성 분석 결과 | 리포트 생성 시 |

**비밀번호는 원문이 아니라 bcrypt로 해시(단방향 암호화)된 값만
저장**되며, 서버 관리자도 원문 비밀번호를 볼 수 없습니다.

## 2. 수집 목적

- 서비스 이용을 위한 본인 확인(로그인)
- AI 모의면접 진행(질문 생성, 답변 평가)
- 표정/음성 분석을 통한 비언어적 피드백 제공
- 채용담당자의 지원자 평가 지원

## 3. 원본 음성/영상의 보관 및 파기

- **보관 방식**: 원본 오디오·영상 프레임은 **AES-256-GCM으로 암호화한
  상태**로 서버 저장소에 보관됩니다. 평문(암호화되지 않은 원본)은 저장
  즉시 폐기되고, 암호화된 파일만 남습니다.
- **보관 기간**: 지원자가 직접 삭제를 요청하기 전까지 보관합니다(즉시
  파기하지 않는 이유: 지원자가 나중에 자신의 답변을 다시 확인하고 싶을
  수 있어, "삭제는 본인이 원할 때"를 원칙으로 함).
- **파기 방법**: (1) 리포트 화면에서 지원자가 개별 오디오/영상을 직접
  삭제 요청하면 즉시 물리적으로 완전 삭제됩니다. (2) 계정을 탈퇴하면
  **30일의 유예기간** 후 계정과 연관된 모든 데이터(면접 기록, 원본
  미디어, 리포트 포함)가 자동으로 물리적으로 완전 삭제됩니다. 두 경우
  모두 소프트 삭제(숨김 처리)가 아니라 실제 삭제입니다.

## 4. 제3자 제공 및 처리위탁

이 서비스는 다음 외부 서비스(AI 모델 제공사, 인프라 제공사)를 이용해
일부 데이터를 처리합니다. 이 회사들은 각자의 개인정보 처리방침에 따라
데이터를 처리하며, 이 서비스가 직접 통제할 수 없는 영역입니다.

| 제공 대상 | 전달되는 데이터 | 목적 |
|---|---|---|
| Groq(AI 추론 API) | 답변 음성 원본(음성→텍스트 변환용), 면접 대화 텍스트(질문 생성/평가용) | 음성 인식(STT), 질문 생성 및 채점 |
| Neon(관리형 PostgreSQL) | 위 1번 표의 모든 데이터(암호화 저장) | 데이터베이스 호스팅 |
| Render(서버 호스팅) | 위 1번 표의 모든 데이터 및 암호화된 원본 미디어 파일 | 애플리케이션 서버·파일 저장소 호스팅 |

**표정 분석(DeepFace)과 음성 운율 분석(librosa)은 외부로 전송하지
않고, 서비스 자체 서버 내부에서만 처리**됩니다.

## 5. 이용자의 권리

- 자신의 원본 오디오/영상을 언제든 리포트 화면에서 삭제 요청할 수
  있습니다.
- 계정 탈퇴를 요청해 본인 데이터 전체의 삭제를 요청할 수 있습니다
  (탈퇴 후 30일 유예기간을 두는 이유: 실수로 탈퇴했을 경우를 대비한
  안전장치이며, 이 기간 중 데이터는 그대로 보존되지만 로그인은
  차단됩니다).

## 6. 보안 조치

- 비밀번호: bcrypt 해시 저장(원문 미보관)
- 인증: JWT(JSON Web Token) 기반, 서명 키는 서버 환경변수로만 관리
- 원본 미디어: AES-256-GCM 암호화 저장
- 통신 구간: 서버 호스팅사(Render)·데이터베이스 호스팅사(Neon)가 제공하는
  HTTPS/TLS 암호화 통신 사용
- 업로드 파일 크기/형식 검증으로 악의적 업로드 방지
- 로그인 실패 반복 시 일시적 잠금(브루트포스 공격 완화)

## 7. 아직 갖추지 못한 것 (정직한 공개)

이 서비스는 시범 단계로, 다음은 아직 없습니다:
- 정식 개인정보 처리방침 법률 검토
- 전담 개인정보 보호책임자(DPO)
- 코드 실행 샌드박스의 완전한 격리(라이브 코딩 기능 — 실행 시간/자원
  제한, 네트워크 차단은 되어 있으나 파일시스템 완전 격리는 안 됨)

## 8. 문의

이 서비스는 1인 개발 MVP로, 별도의 개인정보보호 문의 채널이 아직
마련되어 있지 않습니다. 문의는 프로젝트 관리자에게 직접 연락해 주세요.
