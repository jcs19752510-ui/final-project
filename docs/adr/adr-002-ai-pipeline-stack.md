# ADR-002: AI 파이프라인 스택 (LLM / STT / TTS / 감정분석)

- 날짜: 2026-09-07
- 상태: 승인됨(**STT 결정만 2026-09-08 ADR-008로 대체됨** — 아래 §결정의
  "STT: faster-whisper 로컬 실행" 항목은 더 이상 실제 구현과 다름. 실제
  운영 환경(Render) 실측에서 지연 문제가 발견돼 Groq 호스팅 Whisper API로
  전환. LLM/TTS/감정분석 결정은 이 ADR이 계속 유효. 상세: ADR-008 참조)
- 결정권자: 사용자 (예산 제약 확인 기반, AI 초안 → 방향 승인)

## 배경 (Context)

원본 기획서는 LLM Orchestrator(LangChain), STT(Deepgram Nova-2), TTS(Hume
AI/ElevenLabs), 표정분석(DeepFace), 음성운율(librosa 또는 Hume AI Prosody)을
전제합니다. 사용자 확인 결과 예산은 **Claude Code 구독료를 제외하면 전부
무료**만 사용 가능합니다(2026-09-07). Deepgram·Hume AI·ElevenLabs는 모두
유료 API이므로 그대로 쓸 수 없습니다. ADR-001에서 상호작용 모드를 턴 기반
으로 확정했으므로, 이 ADR은 그 턴 기반 파이프라인 각 단계에 실제로 어떤
무료 구성요소를 쓸지 결정합니다.

## 검토한 대안 (Options)

**LLM (대화 생성 + 채점 + 화이트보드 이미지 평가)**

| 대안 | 장점 | 단점 |
|---|---|---|
| Google Gemini API 무료 티어 (`gemini-2.0-flash` 등) | 무료 티어 존재, 구조화된 JSON 출력 지원, **멀티모달**(이미지 입력 가능 → 화이트보드 평가를 별도 GPT-4V 없이 처리), 한국어 품질 양호 | 무료 티어 RPM/RPD 제한, Google 계정 필요 |
| Groq API 무료 티어 (Llama 3.x) | 추론 속도 매우 빠름, 무료 | 이미지 입력 미지원(화이트보드 평가에 별도 방안 필요), 한국어 품질이 Gemini 대비 불안정 |
| 로컬 Ollama (Llama 3.1 8B 등) | 완전 무료, 오프라인, API 쿼터 걱정 없음 | 로컬 하드웨어 성능에 크게 의존, 한국어/추론 품질이 상용 API보다 낮음, 4주 내 프롬프트 튜닝 부담 증가 |

**STT (답변 음성 → 텍스트, 턴 단위 일괄 처리)**

| 대안 | 장점 | 단점 |
|---|---|---|
| faster-whisper 로컬(오픈소스, Whisper 재구현) | 완전 무료, 오프라인, 정확도 우수 | 실시간 스트리밍 아님(턴 기반이라 문제 없음), 로컬 CPU 사양에 따라 처리 시간 변동 |
| 브라우저 Web Speech API | 서버 인프라 불필요 | Chrome 의존, 서버 쪽에서 원본 오디오를 못 받아 이후 음성운율 분석(피치/떨림)이 불가능해짐 |

**TTS (AI 면접관 발화 음성 합성, 선택 기능)**

| 대안 | 장점 | 단점 |
|---|---|---|
| 브라우저 `SpeechSynthesis` Web Speech API | 완전 무료, 서버 비용 0, 구현 1일 이내 | 감정적 어조 제어(격려/압박 톤) 불가, 음질이 기본 시스템 보이스 수준 |
| gTTS (비공식 Google 번역 TTS 래퍼) | 음질 양호, 무료 | 비공식 API라 요청 제한/차단 리스크 |

**감정/비언어 분석**

| 대안 | 장점 | 단점 |
|---|---|---|
| DeepFace(표정) + librosa(음성 운율) 로컬 | 원본 설계 의도 그대로 유지, 완전 무료 | 로컬 연산 비용(모델 로딩), 프레임 처리 파이프라인 직접 구현 필요 |

## 결정 (Decision)

- **LLM: Google Gemini API 무료 티어(`gemini-2.0-flash` 계열)**를 1차 선택으로
  채택한다. 멀티모달 지원으로 화이트보드 평가(REQ-F-005)까지 별도 서비스
  없이 커버할 수 있어 무료 제약 안에서 원본 기획의 기능 범위를 가장 많이
  보존한다. 무료 티어 쿼터 초과 시를 대비해 Groq(텍스트 전용 백업)를
  2차 옵션으로 코드에서 교체 가능하게(LLM 클라이언트를 어댑터 패턴으로)
  구현한다.
- **STT: faster-whisper 로컬 실행**(모델 크기는 `small` 또는 `base`부터
  시작, 응답속도/정확도 트레이드오프를 개발 중 실측 후 조정)을 채택한다.
- **TTS: 브라우저 `SpeechSynthesis` Web Speech API**를 기본으로 채택하고,
  감정적 어조 제어(REQ-F 5.2.2 원안)는 **MVP 범위에서 제외(Won't)**한다.
- **감정/비언어 분석: DeepFace(표정) + librosa(피치/떨림/속도)**를 원안
  그대로 로컬 실행으로 채택한다. 단, ADR-001에 따라 턴 종료 후 저장된
  비디오/오디오에 대해 **일괄(batch) 분석**하며, 실시간 프레임 스트리밍
  분석은 하지 않는다.

## 결과/트레이드오프 (Consequences)

- Gemini 무료 티어 요청 제한(RPM/RPD)에 걸리면 데모/개발 중 지연이 생길 수
  있음 — LLM 클라이언트는 반드시 provider를 쉽게 바꿀 수 있는 어댑터로
  구현(하드코딩 금지). 이 제약은 `docs/trd/aimock_master_trd.md` §7 미결 항목에
  "무료 티어 쿼터 소진 시 대응"으로 기록.
- TTS 감정 어조는 포기 — 리포트/피드백의 "말투 코칭" 항목에는 영향 없음
  (텍스트 기반 분석은 그대로 유지되므로 평가 기능 자체는 손실 없음).
- DeepFace/faster-whisper 최초 실행 시 모델 다운로드(수백MB~1GB대)가
  필요 — 로컬 개발 환경 최초 셋업 시간에 포함해야 함(작업지시서에 명시).
