# 내부테스트결과서 — Gemini 무료 티어 일일 쿼터 소진(실사용 중 발견)

## 문서 정보
- 일시: 2026-09-08 09:36
- 배경: 사용자가 실제 브라우저(카메라+마이크)로 면접을 진행하던 중,
  턴 5부터 "AI 면접관 호출에 실패했습니다"가 반복되며 다음 질문으로
  진행이 안 되는 문제 보고. **자동화 테스트로는 못 잡는, 실사용 리허설
  에서만 드러난 문제**(1순위 "실제 기기 리허설"을 권한 이유가 바로 이것).

## 원인 (실제 로그로 확인, 추측 아님)

```
Gemini API 호출 실패: 429 RESOURCE_EXHAUSTED.
Quota exceeded for metric: generativelanguage.googleapis.com/generate_content_free_tier_requests,
limit: 20, model: gemini-2.5-flash-lite
quotaId: GenerateRequestsPerDayPerProjectPerModel-FreeTier
```

`gemini-2.5-flash-lite` 모델의 **무료 티어 하루 요청 한도(20건)**를
소진했다. 이 20건은 오늘 하루 동안 개발 중 자동 테스트 + 사용자의 실제
면접 진행이 합쳐져서 소진된 것 — 버그가 아니라 **정직하게 "무료 한도
다 썼다"고 API가 응답한 것**이다.

## 조치
1. `app/ai/llm.py`, `app/ai/report.py`의 모델명을
   `gemini-2.5-flash-lite`(특정 버전 고정) → `gemini-flash-lite-latest`
   (별칭)로 전환. 별칭은 실제로 다른 하위 모델
   (`modelVersion: gemini-3.5-flash-lite`)로 매핑되어, **오늘 소진된
   쿼터와 별개의 새 쿼터**를 쓴다 — 즉시 재개 가능.
2. 429(쿼터 소진)와 다른 일시 오류(503 등)를 **다른 메시지로 구분**
   하도록 `app/ai/gemini_errors.py` 신설 — 429는 "잠시 후"가 아니라
   "무료 사용량 한도 초과, 시간이 더 지나야 함"으로 명확히 안내.
3. 실제 API로 같은 인터뷰에서 3턴 연속 재확인 — 전부 정상 응답.

## ⚠️ 구조적으로 남는 문제 (사람이 알아야 할 것)

**무료 티어는 모델 하나당 하루 20건이 절대적 한계다.** 지금은 새 모델로
바꿔서 임시로 풀었지만, **이 새 모델도 오늘 안에 20건을 넘기면 똑같이
막힌다.** 정확한 계산:
- 면접 1회 = 턴 수(보통 5~15) × 1건 + 리포트 생성 1건
- 즉 **하루에 실사용 리허설 1~2회만 해도 20건을 넘길 수 있다**

**해결책은 임시방편(모델 바꿔치기)이 아니라 두 가지 뿐이다**:
1. **유료 티어로 전환**(Google AI Studio에서 결제 등록) — 한도가 훨씬
   커짐. 무료로 계속 쓰려면 여러 모델을 돌아가며 써서 한도를 늘리는
   식의 편법은 지속 가능하지 않다.
2. **오늘 하루는 실사용 테스트를 아껴서 하기** — 리허설은 신중하게
   1회만, 나머지는 시간 두고 진행.

이건 코드로 해결할 수 있는 문제가 아니라 **사용자가 결정할 사항**이라
자동으로 유료 전환 등을 진행하지 않았다.
