# 내부테스트결과서 — U3-b 실시간 웹캠 프레임 캡처 UI(프론트엔드)

## 문서 정보
- 일시: 2026-09-08 06:00
- 배경: `docs/trd/aimock_u3b_trd.md` §7에서 "별도 결정 필요"로 남겨뒀던
  실시간 웹캠 캡처 UI를 사용자 요청으로 이번에 추가 구현.

## 구현 내용
- `src/frontend/src/pages/InterviewPage.tsx`: 면접장 화면 진입 시
  카메라(영상만) 접근을 시도해 작은 미리보기(160x120, "촬영 중" 배지)를
  띄워두고, 답변(오디오)을 제출하는 매 턴마다 그 순간의 프레임 1장을
  캔버스로 캡처해 `POST /api/v1/interviews/{id}/media`
  (`kind=video_frame`)로 자동 업로드.
- `src/frontend/src/api/endpoints.ts`: `mediaApi.uploadFrame()` 추가.
- 지원자가 별도로 "사진 찍기" 버튼을 누를 필요 없음(자동 촬영 요건 충족).
- 카메라 접근 실패(권한 거부, 카메라 없음 등) 시 안내 문구만 보여주고
  음성 답변 흐름은 그대로 진행 — 부가 기능 실패가 핵심 흐름을 막지 않음
  (기존 마이크 실패 폴백과 동일한 패턴).
- 프레임 업로드 자체가 실패해도(네트워크 등) 답변 제출과 독립적으로
  처리해 면접 진행에 영향 없음.
