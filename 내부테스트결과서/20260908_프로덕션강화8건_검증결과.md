## §3. 특이사항

- 코딩 샌드박스 리소스 제한(`resource.setrlimit`)은 POSIX 전용이라
  Windows 로컬 pytest 실행 시에는 적용되지 않는다(자연히 스킵) — 실제
  Linux Docker 컨테이너에서만 작동하며, 이 환경에서 curl로 직접
  재현·확인했다.
- 프로덕션 nginx 서빙(`docker compose --profile prod`)은 기본
  `docker compose up -d`에는 포함되지 않는다(opt-in). 확인 후 컨테이너를
  계속 켜둘지, `docker compose --profile prod down`으로 내릴지는
  사용자 선택.
- 브루트포스 방어 테스트 과정에서 `sandboxtest@example.com` 계정이
  의도적으로 15분간 잠긴 상태로 남아있다(테스트 부산물, 자연 해제됨).
