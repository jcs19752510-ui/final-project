## 왜 원본 기획서와 이렇게 많이 달라졌는가

`00 파이널 프로젝트 계획서/*.pdf`는 기업 채용팀이 실제로 발주하는 수준의
**엔터프라이즈 프로덕션 스펙**입니다(Kubernetes, Oracle, Pinecone, Hume AI,
GCP, 500명 동시접속 부하테스트, 7명 규모 팀의 7주 WBS). 이 저장소의 실제
개발 조건은 **1인, 4주 이내, Claude Code 구독료 외 전부 무료**입니다
(2026-09-07 사용자 확인). 그 격차를 메우지 않고 원본 스펙을 그대로
TRD/코드로 옮기면 반드시 중도 실패합니다 — 20년차 PM/아키텍트라면 가장
먼저 스코프를 실제 제약에 맞게 재조정하고, 그 결정을 ADR로 남겨 왜 원본과
달라졌는지 추적 가능하게 만듭니다. 아래 ADR들이 그 재조정 기록입니다.
